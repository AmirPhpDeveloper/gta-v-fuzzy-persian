# Banner assets

- English: [`assets/banner-en.png`](../assets/banner-en.png)
- Persian: [`assets/banner.png`](../assets/banner.png)
- Both are 3:1 raster banners created using the built-in `image_gen` tool, then inspected and saved in this repository.
- Reference logo: the [MOBEE GAME Telegram channel](https://t.me/mobeegame) profile image.
- Creator portrait: the public GitHub avatar of [AmirPhpDeveloper](https://github.com/AmirPhpDeveloper), placed inside the banner beside the creator credit at the owner's request.

## Prompt set used

1. **Persian banner:** Create a polished ultrawide GitHub README banner for GTA V Fuzzy Android Persian localization and independent dubbing. Preserve the supplied MOBEE GAME white monogram and wordmark on the left. Charcoal, emerald and restrained violet; sunset city skyline; premium gaming typography. Exact titles: `GTA V FUZZY`, `فارسی‌ساز و دوبلهٔ فارسی`, `Normal + Trainer • Android`; credit `AmirPhpDeveloper × mobeegame`; handle `t.me/mobeegame`. Keep content clear of edges, readable, with no phone mockup or UI cards.
2. **Creator portrait edit:** Preserve the finished 3:1 banner, logo, titles, city, characters and credits. Add the supplied creator's actual GitHub portrait as a circular crop with a subtle emerald outline inside the banner, near the bottom `AmirPhpDeveloper` credit. Preserve the person's face, sunglasses and black jacket; keep all text readable.
3. **English version:** Preserve that finished composition, logo, colors, characters, circular creator photo and credits. Replace only the large Persian headline with `Persian Localization & Dubbing`, using two lines if necessary. Keep `GTA V FUZZY`, `Normal + Trainer • Android` and `t.me/mobeegame` unchanged; no Persian text in the English banner.

The APK icon is a separate asset pipeline: it preserves the original launcher collage and adds native vector Persian lettering. README language/download buttons also use outlined SVG paths so they do not depend on a remote badge service's Persian font support.
